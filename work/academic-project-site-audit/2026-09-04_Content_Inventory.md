## 3. 本科毕业设计覆盖

基线已覆盖：选题、开题、中期、系统实现、论文、答辩、归档，以及实现—测试—论文一致性。

基线缺失或不足：了解要求、课题发布、师生双向沟通确认、任务书展开、文献调研、需求与方案、材料自查、预答辩状态说明、授权成果展示，以及每阶段的 Goal / Tasks / Evidence / Review / Exit Criteria。

注意：仓库无法证明是否存在本科预答辩、正式查重阈值或具体学院时间；只能写为“如当年正式要求适用”。

## 4. 本科科研覆盖

基线没有本科科研独立轨道。可复用的共性内容仅包括周报/综述说明、仓库结构、可复现原则和现有卡片样式。招募渠道、研究方向、真实小任务、项目、竞赛、论文、成果和联系方式均待补，不能虚构。
