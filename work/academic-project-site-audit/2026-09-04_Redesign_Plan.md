# CSMA 学业项目主页重构计划

审计日期：2026-09-04

## 1. 范围与不变项

- 在现有纯静态技术栈内渐进修改，不重建框架。
- 保留全部用户数据、已有页面正文含义、图片、外部链接和 GitHub Pages方式。
- 保留 6 个已有 URL、现有锚点、脚本元素 ID；恢复有证据的历史别名锚点。
- 不删除、移动或退役任何模块；候选仅进入单独报告。
- 不填学生、项目、成果、制度、日期、模板或联系方式等仓库无法支持的事实。
- 不 commit、不 push、不 merge、不自动部署。

## 2. 实施优先级

### P0：发布与隐私安全

1. 增加 `_config.yml`，排除 `work` 与内部验证脚本。
2. 停止身份关联型命名示例在生成页面中的可见渲染，同时保留源数据并登记残余风险。
3. 将账号、token、私人联系方式、未公开材料明确导向受控私有系统。
4. 增加公开发布边界、成果授权和空状态。

### P1：信息架构与培养体系

1. 首页重构为公共门户，设置本科毕设、本科科研、硕士三条同等入口。
2. 完善本科毕业设计完整生命周期和五要素阶段门。
3. 新增本科科研完整生命周期，不承诺论文或获奖。
4. 将硕士页重构为七阶段全流程，并保留既有年级/月份参考视图。
5. 建立共享 Milestones / Deliverables / Templates / Checklists / Evidence / Feedback / Reflection / Integrity / Reproducibility / Archive 机制。

### P2：资源、项目与成果

1. 扩展 `templates.html` 为资源与模板中心；明确当前均为页面说明。
2. 新增 `projects.html`、`outcomes.html`，仅建立发布规则和真实空状态。
3. 新增 `milestones.html`，作为三轨共性入口而非复制全部详情。
4. 新增 `faq.html`、`about.html`，回答使用与边界问题。

### P3：质量

1. 增加 skip link、`aria-current`、语义面包屑、caption/scope、列表语义。
2. 增加统一 focus-visible、reduced-motion、无 JS 导航降级和表格滚动。
3. 增加 canonical、Open Graph、favicon、robots、sitemap。
4. 保留原 PNG，新增 WebP 派生图并做视觉对比。
5. 增加无依赖验证脚本，检查文件、锚点、重复 ID、基础元数据和发布排除。

## 3. 页面修改计划

| 页面 | 计划 |
|---|---|
| `index.html` | 改为学生中心门户；三轨、共性机制、节点、资源、项目/成果空状态、FAQ/About；保留旧锚点别名 |
| `bachelor.html` | 完整生命周期、5 个阶段组、证据与退出条件、交付物/隐私/风险 |
| `master.html` | 七阶段、完整生命周期、保留既有月份表并标来源待核验 |
| `doctor.html` | 保留内容和 URL；统一导航/SEO/a11y；修正私有交接边界 |
| `templates.html` | 扩展资源分类与元数据；保留所有锚点；不声称存在下载文件 |
| `archive.html` | 区分公共成果库与私有过程库；停止身份示例可见渲染；安全交接 |
| 新页面 | 本科科研、项目、里程碑、成果、FAQ、About；缺失事实使用明确空状态 |

## 4. 验证计划

- GitHub Pages 等价 Jekyll 构建；检查 `_site/work` 不存在。
- 无依赖结构/链接/锚点/SEO/重复 ID 扫描。
- secret/个人数据模式扫描，只输出路径。
- `node --check`、`git diff --check`。
- 现有与新增主页面逐页 HTTP 检查。
- 1440、1280、1024、768、390 五种视口截图与 DOM 溢出检查。
- 键盘导航、无 JS 导航、reduced-motion、表格与长标题检查。
- 图片派生版本尺寸和视觉相似度检查。
- 最终记录无法在本地或仓库证据下验证的事项，绝不把“未验证”写成“通过”。
