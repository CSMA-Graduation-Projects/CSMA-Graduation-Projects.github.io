CSMA-Graduation-Projects

学生培养流程与归档管理主页

本主页用于统一说明本科、硕士、博士学生从入组/入学到毕业的培养流程、关键节点、成果要求和归档规范，服务于过程管理、成果导向与长期沉淀。

查看培养层次概览

培养理念

以流程管理为基础，以成果导向为牵引，以培养质量为核心。强调代码、论文、系统、实验与归档材料的一体化沉淀，既服务学生成长，也服务研究组长期建设与知识传承。

培养层次概览

本科（Bachelor）

  • 培养对象：本科生（学士学位阶段）
  • 培养重点：毕业设计、系统实现、论文撰写与答辩归档
  • 管理重点：明确任务节点、过程记录、代码与文档同步归档

硕士（Master）

  • 培养对象：硕士研究生
  • 培养重点：综述、开题、中期、论文与项目产出及归档交接
  • 管理重点：定期检查、阶段性评估与成果沉淀

博士（Doctor）

  • 培养对象：博士研究生
  • 培养重点：前沿研究、持续科研产出、高水平成果与长期系统沉淀
  • 管理重点：长期项目规划、成果质量把控与知识库建设

本科毕业设计流程（时间轴）

选题

确定题目并建立项目仓库

开题

提交开题报告与计划

中期检查

演示进展、问题整改

系统实现

完成代码、测试与部署（若适用）

论文撰写

撰写并校对毕业论文

答辩

组织答辩并完成评审

归档

论文、代码、实验材料归档到学生仓库

成果导向要求

  • 代码、论文、PPT、部署平台与归档材料应保持一致，体现完整闭环。
  • 除论文成果外，应完成真实系统、模块、测试与材料沉淀。
  • 重视项目、论文、系统、实验与过程材料的长期积累与可复现性。
  • 培养目标兼顾继续深造能力与就业竞争力、工程实施能力。
  • 坚持“真正做事、形成成果、留下资产”的实践导向。

仓库命名规范

1. 学生仓库命名规则

格式：YYYY-ug/ms/phd-studentname

示例：

  • 2025-ms-zhoushiyu
  • 2025-ms-oujuntong
  • 2025-ms-lujunchen

2. 课程命名规则

格式：课程缩写名 + YYYY + 学期 + 层次

示例：

  • LPD20252B
  • IRE20251M

说明：B = Bachelor，M = Master，D = Doctor

组织说明 / 管理要求

本组织用于管理学生培养过程与毕业阶段成果归档，强调过程留痕、规范管理、持续检查与按节点推进。鼓励围绕研究组方向开展系统、论文、项目、数据与平台建设，以提高培养质量，提升深造和就业能力。
