# 内容管理指南

## 1. 总原则

- 只发布真实、可核验、适合公开且获得授权的内容。
- 不用示例学生、项目、论文、专利、竞赛或奖项冒充事实。
- 页面说明与学院正式制度分开；正式要求必须有来源、适用范围和核验日期。
- 学生过程证据默认私有，公共页面只列证据类型和通用方法。
- 保留现有路由、锚点、ID 和字段；结构调整不得丢失原数据。

## 2. 新增本科毕业设计课题

当前仓库没有课题数据源。新增前先由负责人确认：

1. 公开标题和稳定 ID；ID 不使用姓名或学号。
2. 问题背景、适用培养轨道、范围和预期能力。
3. 学生任务与导师支持边界。
4. 公开所需资源与先修条件，不公开内部服务器或私有地址。
5. 状态、来源、负责人官方渠道和最后核验日期。
6. 知识产权、合作限制、数据许可和公开范围。

核验完成后，在 `projects.html#available-topics` 使用现有卡片样式增加真实条目；同时从 `bachelor.html` 链接，不改 `bachelor.html` URL。

## 3. 新增本科科研项目

在 `projects.html` 选择“进行中项目”“已完成项目”或“研究原型”，不要把本科毕业设计与本科科研混为一类。至少记录问题、培养目标、公开摘要、阶段、公开链接（如有）、来源、核验日期和授权状态。

申请材料、兴趣/能力评估、小任务反馈、周报和导师意见不得写进公共条目。论文或获奖只能按真实状态描述，不能承诺。

## 4. 更新硕士培养阶段

- 以 `master.html#stage-details` 为权威阶段结构。
- 新增/修改阶段时保持 Goal / Tasks / Evidence / Review / Exit Criteria。
- 年级与月份视图在 `master.html#year-view`；正式日期必须补充来源、适用届次和核验状态。
- 课程名、学分、年度考核、预答辩等制度信息只有在正式材料支持时才能写入。
- 私人培养计划、周报、考核和导师反馈只进入受控系统。

## 5. 维护里程碑

- 共性模型在 `milestones.html`。
- 三轨完整流程分别在 `bachelor.html`、`undergraduate-research.html`、`master.html`。
- 首页只保留摘要和深链，不复制完整日期或阶段说明。
- 里程碑变化需同步检查旧锚点和跨页链接。

## 6. 上传模板或资源

在 `templates.html` 保留现有 7 个锚点。新增真实文件时：

1. 使用清楚、不含个人身份的文件名。
2. 确认文件没有批注、修订记录、作者元数据、个人信息或秘密。
3. 记录名称、适用对象、阶段、类型、文件大小、更新时间、版本、来源和维护责任。
4. 使用相对链接并验证下载。
5. 对 PDF/DOCX 做内容与元数据审查。
6. 不上传已填写的学生模板、签字材料、成绩或评审意见。

## 7. 展示公开成果

在 `outcomes.html` 增加条目前，完成：

- 事实核验：标题、参与者、状态、时间和链接。
- 权利核验：代码、数据、图片、论文和合作内容有权公开。
- 隐私核验：最小公开，不含私人评价或联系方式。
- 授权核验：学生明确同意展示名称、图片、成果和链接。
- 状态核验：论文不得把“投稿中”写成“已发表”，专利不得提前公开未申请内容，竞赛不得夸大奖项。

建议字段：`id`、`title`、`track`、`type`、`summary`、`status`、`sourceUrl`、`verifiedAt`、`public`、`consentToPublish`、`displayName`、`visibility`。默认 `public=false`。

## 8. 更新 News / Updates

当前没有新闻数据源。首页 `#updates` 只展示资料状态。新增新闻时必须有真实事件日期、发布日期、标题、摘要、来源链接和公开权限；不得把计划写成已经发生的事实，也不得发布内部会议纪要。

## 9. 学生公开授权

- 授权应能证明主体、范围、用途、展示方式、日期和撤回/更正渠道。
- 未回复、历史存在或公开仓库可见不等于同意。
- 不得把所有学生批量设为公开。
- 撤回公开展示和保留内部合法归档分开处理。
- 授权记录本身可能含个人信息，应存于受控私有系统，只在公开数据保留状态字段。

## 10. 发布前内容检查

- 所有事实有仓库或权威来源支持。
- 所有公开人物、项目、成果和图片有授权。
- 所有内部链接、锚点和下载存在。
- 不含账号、凭据、私人联系方式、私有 URL 或受限数据位置。
- 不公开成绩、评价、健康、困难、处分、推荐信或未公开研究。
- 页面 description 与正文一致，不制造搜索引擎误导。
