# 双语门户与随笔：需求、设计与维护

日期：2026-10-19。状态：本地实现与验收，待演示确认；未授权发布本轮改动。

## 需求与依据

用户确认中英文覆盖整个培养门户：不同阶段的国际学生应能读懂指南、流程图、工具、模板和随笔，而非只有导航或简介采用英文。流程图继续直接显示在网页中。导航采用“随笔 / Essays”，中文页题“培养随笔”，英文页题“Essays on Mentoring”；“关于 / About”保持简洁，页题为“关于我们 / About Us”。

政策、科研诚信及工具推荐沿用前期已核实的官方来源，出处仍保留在依据页和工具指南。翻译不新增学校学位制度，不把国内通用培养流程推定为每位国际学生的正式要求。开题、预答辩、查非、送审、学位授予分别解释；学位类型、授课语言、课程、专业实践、成果资格、时限仍由适用学校和项目文件确认。工具安装情况仅说明本机可见应用，不证明账号、许可、服务或实验可用。

本轮修改前创建完整同级备份 `CSMA-Graduation-Projects.github.io-backup-20261019-024632`：527 个文件、737 个目录项，文件清单、模式、哈希一致，源目录在复制期间未变化，`git fsck` 通过。基线为 `befdced`。恢复时先保存当前工作，再将备份复制到独立恢复目录核验；不直接覆盖当前目录。

## 信息结构与实现

- 每种语言 23 个顶层页面，稳定路由分别为 `/页面.html` 和 `/en/页面.html`。两种语言共用阶段、模板和流程节点 ID，保留历史链接。
- 两篇中文随笔及对应完整英文版，分别放在 `_essays/`、`_essays_en/`；两篇原有新闻具备 `_news_en/` 对应版。
- 34 个阶段、10 张流程图、7 类工具任务和 24 份模板逐项翻译。英文页面、模板、SVG、draw.io、完整离线手册及 ZIP 均独立可用。
- `scripts/build-training.py` 共享页面生成逻辑；`scripts/i18n.py` 和 `scripts/i18n/en.json` 维护界面译文；正文使用显式翻译的 JSON、HTML 和 Markdown。没有引入翻译接口或运行时网络依赖。
- 样式沿用海军蓝、深青与克制的金色；随笔使用较宽行距和限定正文宽度。语言按钮与导航分开，小屏采用可访问菜单。流程图使用原生 HTML，打印、下载为可选操作。
- 语言切换保留路径对应关系、阶段锚点及清单的路径/阶段参数。个人勾选和日期按语言分别保存，避免不同语言文本指纹使已有记录被重置；导出文件用于留存，不构成导师验收或学校批准。
- HTML 标注页面语言、对应语言链接、规范 URL 和当前栏目；新闻与随笔使用完整独立页面，页面源码、站点地图及本地构建均纳入验证。

## 编辑入口

| 内容 | 中文源 | 英文源 |
| --- | --- | --- |
| 培养阶段、流程、工具、模板索引 | `assets/data/*.json` | `assets/data/en/*.json` |
| 可填写模板 | `assets/templates/*.md` | `assets/templates/en/*.md` |
| 四个共同指南 | `scripts/training-pages/*.html` | `scripts/training-pages/en/*.html` |
| 保留的七个栏目正文 | 根目录相应 HTML | `scripts/english-pages/*.html` |
| 新闻 | `_posts/YYYY-MM-DD-slug.md` | `_news_en/YYYY-MM-DD-slug.md` |
| 随笔 | `_essays/slug.md` | `_essays_en/slug.md` |

随笔使用相同英文 slug 配对，标题和正文自然翻译。元数据必填 `title/date/topic/summary/author/lang/published`，正文从二级标题开始。模板在 `docs/content-templates/essay.md` 和 `essay-en.md`，默认 `published: false`。只有明确发布且日期不晚于当前时间的文章进入列表和站点地图；未完成材料不放入公开仓库。文章不冒署个人作者，首批两篇使用“本站整理 / Site editorial”。

首页各显示最新两篇随笔，列表显示全部已发布文章，正文带返回入口。`scripts/editorial.py` 统一生成双语布局、列表和站点地图。不要直接修改派生 HTML、下载 ZIP 或 `assets/training-en.js`。

成果和学生故事共用原始核验记录。可选 `en` 对象存在时必须完整：成果为 `title/category/contributors/summary/link_labels`；学生故事为 `name/degree/cohort/summary/highlights/link_labels`。`link_labels` 与原链接逐项对应，`highlights` 与原经历数量一致。ID、日期、照片、URL 共享。没有完整译文的记录不回退显示中文。当前两类真实记录仍为空，保持真实空状态。

## 验收与发布

先运行生成器，再用 Jekyll 构建实际站点；检查双语结构、正文完整性、内部链接、公开边界、下载包哈希和图源；在六种屏幕宽度下验证菜单、布局、随笔及英文界面。功能验证包括模板检索/复制/下载，清单保存/导出，中英状态隔离，语言切换位置保留，无 JavaScript 阅读和流程图默认显示。实测结果另存验收记录，不以前期中文版本的结果替代本轮结果。

```sh
python3 -B scripts/build-training.py
jekyll build --safe --trace
node scripts/validate-site.mjs --build
node scripts/validate-training.mjs
node scripts/validate-workflow-tools.mjs --build
python3 -B scripts/validate-bilingual.py
node scripts/privacy-scan.mjs --build
git diff --check
```

本地验收、演示确认、提交推送、检查 Pages 和线上结果是分别完成的步骤。当前仅开展前两步，发布须等待用户确认。
