# 演示与后续维护

本次实现及本地演示完成，2026-10-18 已获得继续发布的确认。发布后使用[正式主页](https://csma-graduation-projects.github.io/)、[模板库](https://csma-graduation-projects.github.io/templates.html)与[阶段自检](https://csma-graduation-projects.github.io/planner.html)。下列本地入口用于后续维护和复查。

## 三分钟演示顺序

1. 打开本地首页 `http://127.0.0.1:8766/`：看四条培养路径与阶段、模板入口。桌面与手机均可使用。
2. 进入硕士培养：侧栏直接定位“格式、查重、查非与 AI 使用说明”或“匿名送审、评阅意见与异议处理”，查看进入条件、操作、交付、验收及整改。旧培养栏目链接继续有效。
3. 点击“自检本阶段”：选择阶段，勾选一项，刷新验证保留；切换阶段不会混用记录。导出后得到 Markdown 清单，含待补证据与审核记录。测试勾选仅代表自检。
4. 打开模板库：搜索“开题”或“专业实践”，展开正文预览；复制或下载单份模板，或下载 24 份全套 ZIP。
5. 打开“依据与校本要求核对”：看正式规则、工作建议和待核验信息的区别；核对表包括学位类型、课程、实践、成果、检测、评阅、答辩与学位手续。
6. 打开归档页：看原始/工作/公开材料分层、运行说明、SHA-256、恢复与权限交接的完成条件。

## 后续维护入口

培养内容改 `assets/data/pathways.json`；模板正文改 `assets/templates/` 并同步 `assets/data/templates.json`；共用指南改 `scripts/training-pages/`。执行生成器后，生成页面、下载包和数据一起审查。不要仅手改生成页面。

```sh
python3 scripts/build-training.py
python3 scripts/verify-training-package.py
node scripts/validate-training.mjs
jekyll build --safe --trace
node scripts/validate-site.mjs --build
node scripts/privacy-scan.mjs --build
git diff --check
```

年度变更先更新校本来源和适用范围；新版清单内容变化时不沿用旧勾选。学校正式表格仍由指定系统取得；填写后的个人材料不加入公共模板库。新闻只记录实际发布的指南、安排和成果更新。

每次正式发布均审查文件清单、提交并推送，随后核对对应提交的 GitHub Pages 构建和线上入口。以[构建记录](https://github.com/CSMA-Graduation-Projects/CSMA-Graduation-Projects.github.io/actions)确认部署结果，并复核线上模板下载、阶段清单与手机布局。
