# 培养门户详细设计

日期：2026-10-18。

## 信息架构

首页以“我现在该做什么”为主要入口，展示本科科研、毕设、竞赛、硕士四条路径。保留博士、新闻、成果、榜样、关于等原有栏目。培养内页采用阶段目录和逐阶段任务卡；公共工具汇集阶段清单、模板、日常管理、学术规范、归档及官方依据。

每张阶段卡依次展示：阶段目标 → 进入条件 → 操作 → 交付 → 验收 → 整改 → 下一步。学生先定位当前阶段，再取模板、完成任务和发起审核。阶段不是纯时间顺序：文献、实验、写作、成果记录持续迭代，正式手续依学院时间办理。

## 内容模型

- `assets/data/pathways.json`：四条培养路径与阶段；阶段的进入条件、行动、交付、检查和模板关联为结构化字段。
- `assets/data/templates.json`：24 个模板条目的名称、类别、适用对象、说明和文件地址。
- `assets/templates/`：公开空白 Markdown 模板及全套下载包。
- `scripts/build-training.py`：从同一数据源生成培养页、首页、模板页、共用指南和静态 Markdown 培养手册，避免页面与交互清单各写一套内容。
- `assets/training.js`：渐进增强的模板检索、阶段选择、清单保存、导出及打印交互。
- `assets/training.css`：新布局与共用视觉样式，保留原有站点样式基础。

页面生成后继续由现有 Jekyll 构建新闻及公开数据，不引入前端框架、服务端或外部字体。构建脚本只写明确列出的派生文件，保留其他页面和数据。

## 交互

阶段工具通过 URL 参数保存所选路径和阶段，方便从阶段页直达。每个阶段有独立清单状态；浏览器本地存储只包含阶段 ID、勾选状态及可选目标日期，不包含个人材料。数据版本变化时不沿用旧勾选；无痕/禁用存储情况下告知用户仅当前会话可用。导出是本地文件，不发送网络请求。

模板页支持文本与类别组合筛选，结果数量可被辅助技术读取；无匹配显示重置入口。无 JavaScript 时全部模板和培养指南仍可阅读、下载。打印保留正文并展开阶段，去除导航和按钮。

## 视觉

延续 CSMA 深蓝标识，以暖白背景、墨蓝正文、少量青绿色和暖金点缀组织信息。首页采用宽留白、明确的中文大标题、四轨入口与简洁阶段图。内页强调清晰可扫读，避免大段挤在表格中；长流程使用可定位的侧栏目录。移动端目录转为顶部可折叠区域，卡片单列，按钮触控范围不少于 44px，内容不依赖悬停。

## 兼容与验证

旧 URL 保持，历史阶段锚点映射到对应新阶段。新闻、成果和榜样使用既有 Jekyll includes。采用结构验证、内容约束、下载包验证、真实 Jekyll 构建、浏览器交互、多个宽度溢出与截图复核。测试产物保存在仓库外，本地预览仅服务 `_site/`。

## 发布与维护

发布按本地验收、演示确认、提交推送和线上复核的顺序进行；2026-10-18 已获得继续发布的确认。研究内容变更先改 JSON 或 Markdown 源，再运行生成器与验证器；学校规定每学年及毕业批次复核，明确版本、生效范围与查询日期。旧制度不覆盖删除，记录替代关系。公开空白模板与填写后的受控材料必须分开保存。
