# 科研与竞赛合作入口

日期：2026-10-20。状态：本地实现与验证完成，尚未提交或推送。上一个已发布版本为 `39138ad`，前一轮联培栏目及本轮科研合作入口仍属于同一组待发布修改。

## 需求与调研

用户希望吸引更多外校及海外优秀学生，共同开展科研、竞赛和人才培养。新入口应让本科、硕士及博士学生知道可以讨论什么、怎样参与、如何联系、从何开始，以及合作后能形成哪些能力。原联培指南继续承担接收派出、双方职责和正式培养衔接。

2026-10-20 核验的公开来源：

- [导师公开主页](https://h-jp.github.io/)：人工智能、智能软件工程和智能机器人三个研究方向；主页提供公开联系渠道。本轮仅链接公开主页，不从其他材料搬入私人联系方式或未公开课题。
- [MIT UROP 学生入口](https://urop.mit.edu/students/)：参考其从学习目标、导师交流到共同研究计划的参与路径。本站六步路径是本地设计，不是 MIT 项目或规则的复制。
- [EPFL DSLab 科研实习与博士访问入口](https://dslab.epfl.ch/positions/internship)：参考其清楚说明研究兴趣、相关经历及可参与日期的联系结构；不迁移其期限、成绩材料、推荐人或资助条件，也不暗示合作关系。

## 信息架构与设计

导航继续使用“联培 / Joint Training”。`joint-training.html` 顶部增加两个入口：寻找科研或竞赛合作，以及安排联合培养。新页面 `research-collaboration.html` 与 `/en/` 对应版本归属联培，并从首页、资源和五条培养路径进入。

新页面采用现有页面宽度、配色、卡片、响应式表格及默认展开流程图，先呈现邀请与研究兴趣，随后给出九个对应章节：欢迎交流、研究方向、合作方式、分层起点、首次联系、开始合作、小任务约定、持续成长、常见问题。中文和英文的段落、锚点、联系目的与流程一致。

普通首次交流不要求已经有两位导师、发表论文、完整课题或联培协议。已有课题或导师的学生说明可分享范围和现有安排；需要正式访学、学分、毕业设计或学位衔接时，再转入现有联合培养指南。研究方向中的小任务明确标为交流示例，不作为已开放课题或接收名额发布。

## 可执行内容

| 学生阶段 | 可带来的材料 | 合作中的成长目标 |
| --- | --- | --- |
| 本科 | 课程作品、阅读记录、编程练习或具体问题 | 解释概念，完成小任务，形成验证与协作习惯 |
| 硕士 | 文献梳理、复现、实验记录及本人贡献 | 收敛研究问题，设计比较，形成证据并解释局限 |
| 博士 | 研究主线、独立工作、问题与证据 | 讨论原创贡献和互补研究，明确合作与独立贡献 |

可讨论科研入门、共同研究、开源工程、竞赛、阶段访问或论文合作，以及远程、到访或混合形式。国际参与明确沟通语言、时区和异步记录；竞赛队伍资格按实际规则核对。

首次联系只需简短背景、具体兴趣、代表材料或学习尝试、时间与参与方式、期待支持。新增 `collaboration-interest` 双语模板，含可填写字段、发送前检查和可复制联系短文；未建设申请收集系统，也未发送任何邮件。

合作流程为：选择问题 → 发送简介 → 双向交流 → 约定并完成小任务 → 反馈复盘 → 确认后持续合作。六个行动节点之外有两个判断和两个调整支路；暂缓、调整或友好结束均为正常结果。小任务约定学习目标、规模、支持与反馈日期、贡献和成果用途；涉及实际项目交付时进一步确认适用工作条件。
