# 实现与测试记录

日期：2026-10-18。记录范围：演示前的本地实现与验收快照。演示后已获得继续发布的确认；以下测试结果不代替 GitHub Pages 部署与线上验证。

## 实际交付

- 4 条培养路径、34 个阶段：本科科研 7、本科毕设 8、学科竞赛 6、硕士 13。
- 每阶段有目标、时机、进入条件、具体行动、交付物、完成标准、未通过处理、下一步和模板关联。
- 24 份实质可填写 Markdown 模板，每份含用途、填写指导、字段、证据和验收。专门补齐专业实践、工程需求设计测试报告及本科毕设任务书底稿。
- 日常管理、学术规范、数据资料归档和官方依据 4 份共用指南。15 项核心一手来源逐项标注日期与适用边界。
- 阶段自检支持路径/阶段直达、本地保存、个人计划日期、进度、导出、单阶段重置和存储异常回退；不代替正式审核。
- 模板支持关键词/类别组合筛选、无结果反馈、全文预览、复制、单份下载与 ZIP 整包下载。
- 离线培养手册包含全部 34 阶段及 4 份共用指南，包含官方来源链接。ZIP 共 27 项：24 模板、README、手册、SHA256SUMS。
- 保留原新闻、博士、项目、成果、榜样、关于栏目；保留旧页面 URL 及历史阶段锚点，修正旧 FAQ 与新内容冲突。

调研阶段的模板建议按实际使用合并成 24 份：查重、查非、匿名与版本检查整合为提交自检；竞赛计划、提交与复盘使用同一模板；校本规则与年度状态在同一核对表登记。每个用户指定环节均有对应字段与配套入口。

## 技术实现

保留 Jekyll 3.10 兼容架构。Python 标准库生成静态 HTML、Markdown 和确定性 ZIP；JSON 是路径与模板元数据的单一来源。交互仅使用原生 JavaScript 和浏览器本地存储，无账号、上传、邮件发送或后台审批。

新增视觉沿用深蓝标识，使用暖白、墨蓝、青绿和少量金色。首页分身份与任务导航，培养页使用可定位阶段目录，手机端可折叠；模板采用卡片、搜索和展开预览。无需外部字体、图片服务或第三方脚本。

本地使用已有 Ruby 3.3.6 / Jekyll 3.10.0 环境执行 `jekyll build --safe --trace`。没有修改外部研究组仓库或安装站点依赖。预览只服务 `_site/` 发布产物。

## 审阅中发现并关闭的问题

1. FAQ 仍写“无实际下载文件”、使用旧月份解释：已替换成 24 份真实模板与校本日期核对。
2. 预答辩被误放在固定的盲审后位置：已改为按适用制度确认，可在送审前完成必要前置环节。
3. 个别文字笼统要求移交密码：已统一为组织资源的所有权、管理角色与访问权限交接，不移交个人账号密码。
4. 校本模板字段不够完整：已增加规则来源、生效范围、核验记录和毕业各环节核对行。
5. 模板卡片继承旧 flex 样式导致正文挤窄：截图复核发现后修正，增加了阅读宽度断言；桌面和手机截图已更新。
6. 新版浅色页头继承旧浅色面包屑：已提高对比度；长阶段目录编号已固定宽度，避免折行。

## 验证边界

自动文本与敏感模式检查不等于对所有信息作出合规保证，故结合了逐份模板及新旧内容人工审阅。本记录中的本地验收没有执行学校系统审批、邮件、云端部署或真实学生培养记录处理。未得到具体学校与学院信息，因此正式门槛和日程保留校本核对，不猜测。

部分官方页面直连有超时或重定向问题，本次通过其官方搜索索引、官方同文或交叉来源核对，并在调研记录中保留限制；没有宣称所有外部链接都实时返回 200。旧查非 PDF 仅用于术语解释，不采用其中阈值。
