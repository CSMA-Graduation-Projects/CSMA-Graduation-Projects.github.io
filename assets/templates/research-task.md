# 科研训练任务卡模板

用途：把本科科研训练或硕士研究中的一个阶段目标拆成可开始、可提交、可验收的小任务。适合初次阅读、复现、数据核查、原型实现或问题验证，不以“熟悉某领域”作为唯一任务。

填写说明：一张卡只处理一个主要问题。目标应与学生基础、课程安排和资源匹配；先明确最小交付，再列可选扩展。示例“在授权小样本上跑通基线并解释一个失败案例”比“学习大模型”更可验收。

## 一、任务定义

| 必填项 | 填写内容 |
| --- | --- |
| 任务编号、负责人、日期 | ［唯一编号、开始与检查日期］ |
| 培养阶段与任务来源 | ［本科科研训练／毕业设计／硕士；关联阶段计划］ |
| 要回答的具体问题 | ［为什么做、结果用于哪个后续决策］ |
| 当前基础与前置材料 | ［必要概念、指定论文、已有代码；阅读或运行状态］ |
| 最小完成目标 | ［可检查的结果；例如能复述机制并提交运行记录］ |
| 不在本次范围的内容 | ［本次不扩展的数据、算法、系统或额外功能］ |

## 二、步骤与交付

| 步骤 | 要做的事 | 产出与证据位置 | 自查方法 | 截止日期 |
| --- | --- | --- | --- | --- |
| 理解问题 | ［阅读并解释输入、输出、假设］ | ［短说明、图示或阅读笔记］ | ［能否用一个具体例子解释］ | ［填写］ |
| 最小尝试 | ［使用许可范围内的样本或环境］ | ［代码、配置、实际日志］ | ［他人能否重复关键步骤］ | ［填写］ |
| 解释结果 | ［核对输出与一个失败案例］ | ［观察、疑问、后续建议］ | ［结论是否超出证据］ | ［填写］ |

可选扩展：［只有最小目标验收后再做的内容；不把扩展默认为必做］。

## 三、资源、阻碍与求助

- 必要资源：［数据许可、软件、设备权限、预计运行成本；不得记录密钥］。
- 风险与伦理：［是否涉及个人数据、外部服务、未公开资料；前置审批］。
- 遇到阻碍时：记录［复现步骤、错误信息、已尝试办法、最小示例］后提出具体问题。
- 检查节点：［何时提交什么供讨论；无法按时完成时何时说明影响］。
- 证据说明：真实运行、作者结果、保存记录回放和人工样例分别标注；未运行不能填“已复现”。

## 四、验收与下一步

- [ ] 必交材料均有可访问的位置，文件和描述相符。
- [ ] 学生能解释关键过程、结果与局限，而非仅展示截图。
- [ ] 成功和失败均据实记录，引用、授权及 AI 辅助情况清楚。
- [ ] 后续建议基于本次发现，任务没有无限扩展。

验收结果：［通过／补充后复核／调整任务；说明具体原因］。

反馈与行动：［审核人、日期、需要修改的内容、责任人、复核日期］。

学习反思：［本次掌握了什么；仍不理解什么；下一张任务卡解决什么］。
