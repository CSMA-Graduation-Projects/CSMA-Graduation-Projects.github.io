# 学习与成长复盘

> 适用于本科科研训练、毕业设计、竞赛、硕士与博士研究。用一份记录连接能力目标、学习实践、真实证据、反馈和下一步。可在现有周报或阶段报告中引用本表，避免重复填写。本模板用于学习与指导，不具有学校审批或正式考核效力。

## 7. 提交前自查

- [ ] 能力目标可通过解释、操作、比较或判断观察。
- [ ] 起点、实践和复盘均指向实际记录，并标明版本或日期。
- [ ] 所读资料有可定位来源，与本轮任务有关。
- [ ] 观察、解释、假设和计划分开记录，未完成项保持真实状态。
- [ ] 成果质量、个人贡献与能力成长分别说明。
- [ ] 获得的帮助与本人核对过程清楚；需要的支持已写明。
- [ ] 反馈有处理理由、修改证据和复查安排。
- [ ] 迁移与下一步具体可做；正式培养条件已另行核对。
- [ ] 共享材料不含无关个人信息、密钥或未获准公开的研究资料。

## 填写示例：待执行计划

以下为示例，不代表任何学生已完成的结果。

- 本轮能力：能够解释测试失败与代码缺陷之间的区别。
- 起点证据：目前只有一段错误消息的转述，尚未检查环境因素。
- 学习任务：阅读项目测试说明，设计区分环境因素与代码行为的检查。
- 拟交证据：命令、环境信息、输出和解释表；执行后再填写实际结果。
- 支持需求：请指导者检查两种解释是否有相应的区分检查。
- 迁移任务：更换一条失败记录，再尝试说明可能原因及证据缺口。
