# 单篇论文阅读与复现判断模板

用途：记录精读或定向泛读的实际收获，为讨论、综述和复现决策提供依据。按阅读深度填写，未读或未验证的部分明确标注，不要求把每篇文献都复现。

填写说明：先用自己的话说明论文解决什么问题，再记录关键证据。摘录须标明页码与引用，避免把原文改写当作原创结论。示例“表三在特定数据上改善指标”只支持相应条件，不自动说明方法普遍有效。

## 一、文献信息

| 必填项 | 填写内容 |
| --- | --- |
| 阅读人、日期、阅读类型 | ［精读／泛读／针对某问题核查］ |
| 题名、作者、年份与版本 | ［正式发表版本／预印本版本；版本日期］ |
| 可核验来源 | ［DOI、官方论文地址；代码和数据官方地址分别列出］ |
| 阅读动机 | ［本课题的哪个问题需要这篇论文提供帮助］ |
| 实际阅读范围 | ［全文／指定章节／仅摘要；未覆盖部分］ |

## 二、问题、方法与证据

| 要点 | 自己的概括 | 证据位置与限制 |
| --- | --- | --- |
| 研究问题与使用场景 | ［谁遇到什么问题］ | ［引言页码；真实案例还是构造示例］ |
| 关键假设与输入输出 | ［方法成立需要的条件］ | ［章节或算法编号］ |
| 方法机制 | ［用三至五步说明，不仅列模型名称］ | ［图号、伪代码；不能理解处］ |
| 评价设置 | ［数据、基线、指标、预算与重复方式］ | ［实验章节；公平性限制］ |
| 主要结论 | ［数据真正支持什么］ | ［表格或案例；是否存在负面结果］ |

## 三、判断与课题关联

- 作者明确承认的局限：［原文依据］。
- 自己识别的疑问：［哪些假设可能不成立，需要什么证据才能判断］。
- 与已读工作的关系：［相同点、差异点、能否直接比较；列文献编号］。
- 可借鉴内容：［具体方法、评价办法或表达方式；如何适配本课题］。
- 不宜直接迁移的内容：［领域、资源、数据授权或指标差异］。
- 后续阅读：［为解决哪个疑问阅读哪项材料，避免无限扩展书单］。

## 四、复现判断与验收

复现决定：［不复现／先做最小核验／安排完整复现；说明价值与成本］。

若已运行，填写［代码版本、环境、数据版本、命令、原始日志相对路径、实际观察］；若仅查看作者结果或回放保存记录，分别写“作者报告”或“保存记录回放”，不得写为本次真实运行。失败也要记录错误与排查边界。

- [ ] 能独立解释问题、机制、证据和主要局限。
- [ ] 关键结论有出处，没有将个人推测写成论文结论。
- [ ] 复现状态据实填写，讨论问题具体且可回答。

讨论与验收记录：［讨论人、日期、已澄清问题、待办、是否进入综述矩阵］。
