# 选题论证与范围界定模板

用途：用于本科毕业设计、科研训练或硕士选题的比较和决策。重点回答问题是否真实、已有方法哪里不足、当前资源能否完成，而非先给题目堆砌技术名词。最终选题须按学院程序确认。

填写说明：先记录证据，再提出判断；“预计有效”属于假设，不能写成结果。每个候选题至少说明一个可能导致放弃的条件。创新要求和成果形式引用本培养类别的正式依据，不自行设定统一标准。

## 一、选题信息

| 必填项 | 填写内容 |
| --- | --- |
| 项目代号、拟题、版本日期 | ［题目应体现对象、问题或目标，避免范围过宽］ |
| 培养类别与时间窗口 | ［科研训练／毕业设计／学术或专业硕士；可投入周期］ |
| 选题来源与适用要求 | ［实际场景、前期项目或文献；学院文件名称与链接］ |
| 一句话研究问题 | ［在何种场景下，什么对象存在什么可验证的问题］ |
| 预期使用者与价值 | ［谁会使用结果；若问题解决，具体改变什么］ |

## 二、问题依据与候选方案

| 证据或候选方向 | 已知事实与来源 | 尚不确定的判断 | 下一步验证 |
| --- | --- | --- | --- |
| ［实际案例／论文／需求记录］ | ［链接、时间、样本范围］ | ［是否具有代表性］ | ［如何收集反例］ |
| ［候选题甲］ | ［现有方案及主要不足］ | ［核心假设］ | ［最小实验及周期］ |
| ［候选题乙］ | ［同上］ | ［同上］ | ［同上］ |

区分真实场景证据、公开数据结果、人工构造示例和待验证推测。受控示例只能说明机制，不直接证明普遍需求。

## 三、拟采用题目的边界

- 研究对象与输入输出：［明确任务单位、使用环境、输入条件、产出形式］。
- 核心问题：［列一至三个可回答的问题，并说明对应观察指标］。
- 纳入范围：［数据、场景、方法、版本与适用条件］。
- 排除范围：［本阶段不研究哪些情况，并说明原因］。
- 基线与评价：［与什么比较；指标定义、比较公平性及失败案例如何记录］。
- 预期贡献：［方法、系统、数据或经验结论；说明与现有工作的差异证据］。
- 可行性：［数据许可、设备、技能、协作支持和最小验证结果；未执行写待执行］。
- 风险与退出条件：［如数据无法合法获取、基线已足够、预期增益无法观察时如何缩小或换题］。

## 四、决策与验收

选择理由：［为什么选此题、放弃其他候选；不能仅写“感兴趣”］。

- [ ] 问题由可追溯证据支撑，假设与已知结论分开。
- [ ] 题目范围与时间、资源、培养要求匹配。
- [ ] 数据授权和可能需要的伦理审批已列入前置条件。
- [ ] 最小验证有明确交付物、期限和停止条件。

评审意见：［确认／修改范围／暂缓；理由、责任人、复核日期］。确认记录：［实际审核人及日期］。
