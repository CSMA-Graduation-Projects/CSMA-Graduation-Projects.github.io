# 实验、复现与运行证据模板

用途：记录一次实验计划及实际执行，支持本科项目验证、硕士研究和论文复核。每份记录对应明确配置与一组可解释的运行；计划、执行、分析分开填写。

填写说明：运行前写问题和判据，运行后补实际结果。保留失败、超时和排除样本，不只展示最优输出。涉及数据授权、个人信息或伦理审批的任务，应先满足相应前置条件。

## 一、运行身份与证据类型

| 必填项 | 填写内容 |
| --- | --- |
| 实验编号、负责人、执行日期 | ［唯一编号；起止时间和时区］ |
| 要回答的问题及预期判据 | ［可证伪的假设；指标及判定方式］ |
| 证据类型 | ［本次真实运行／保存记录回放／作者报告／人工示例／尚未执行，只选实际情况］ |
| 代码与环境 | ［仓库相对位置、提交或文件版本、依赖锁定、设备、模型与服务版本］ |
| 数据与许可 | ［数据版本、划分方法、授权范围、脱敏及审批状态］ |
| 执行入口与参数 | ［完整命令或脚本、配置、随机种子、预算；密钥以环境变量名称代替］ |

## 二、设计与执行记录

- 比较对象：［基线、消融或对照；相同数据与预算如何保证］。
- 指标定义：［公式、计量单位、统计单位、分母、越高或越低越好］。
- 重复与不确定性：［重复次数的理由、种子来源、波动或区间的计算方式］。
- 样本排除与中断规则：［事先约定条件；临时变化另记原因］。
- 成本与异常：［时间、资源消耗、超时、错误、重试及实际影响］。

| 运行编号 | 配置或种子 | 状态 | 原始日志／输出相对路径 | 指标与成本 | 备注 |
| --- | --- | --- | --- | --- | --- |
| ［填写］ | ［填写］ | ［完成／失败／中断］ | ［可定位到原始记录］ | ［含分母和单位］ | ［失败原因或偏离计划］ |

## 三、分析与边界

实际发现：［只陈述记录支持的结论，说明差异大小和波动］。

失败与反例：［哪类样本无效或更差；如何影响原假设］。

局限：［样本规模、预算、版本、人工判断及外部有效性］。

回放说明：若使用保存记录，填写［记录来源、生成时间、校验值、回放脚本及能验证的范围］。回放可验证解析和统计逻辑，不能证明当前模型、网络服务或外部系统成功执行。

## 四、复核与验收

- [ ] 日志、配置、数据版本和代码能相互对应；无凭据或未经授权的数据。
- [ ] 成功、失败和排除情况完整，指标分母可复算。
- [ ] 图表可追溯到原始记录；没有将人工样例视为实测结果。
- [ ] 已说明是否由他人重跑，复核范围与结果据实记录。

复核记录：［复核人、日期、实际执行步骤、差异及处理］。结论状态：［支持／部分支持／不支持／证据不足］。下一步：［任务、责任人、期限］。
