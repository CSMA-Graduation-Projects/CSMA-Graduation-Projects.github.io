# 科研与竞赛合作意向

用途：帮助外校、海外及本校学生介绍兴趣和时间安排，开启一次科研或竞赛合作交流。本科、硕士、博士均可使用，初次接触科研也可以填写。

用中文或英文简要填写即可，通常控制在 1—2 页；不清楚的项目可写“待讨论”，暂时没有的经历可写“暂无”。本模板不设置统一 GPA、论文数量或学校排名门槛，首次联系无需附证件、成绩单、生日或国籍等信息。

## 一、简单介绍自己

| 项目 | 填写内容 |
| --- | --- |
| 希望如何称呼你 | ［姓名或常用称呼］ |
| 当前学习阶段、专业与学校 | ［本科／硕士／博士、年级、专业、学校；其他阶段可说明］ |
| 个人主页或作品页（可选） | ［可公开分享的链接；没有可留空］ |

## 二、你想研究什么、学会什么

- 感兴趣的具体问题或方向：［用自己的话写 2—3 句；可从阅读、课程或遇到的问题出发］。
- 希望形成的能力：［例如读懂并解释一篇论文、完成一次小规模复现、设计实验、开发原型或组织竞赛协作］。
- 当前已有基础与想获得的帮助：［会什么、尝试过什么、哪个环节希望获得指导；不要求已经确定完整课题］。
- 代表工作及本人贡献：［提供 1—2 项可分享的课程项目、阅读笔记、小练习、作品或研究；附链接或简短说明，写清本人做了什么、哪些部分来自合作或工具帮助］。

没有现成作品时，介绍一次学习尝试或一个准备开展的小练习也可以。只分享你有权限提供的材料。

## 三、可参与的方式与时间

| 项目 | 填写内容 |
| --- | --- |
| 希望的参与方式 | ［远程科研／竞赛协作／短期交流／驻校研究／希望先讨论］ |
| 预计开始与结束时间 | ［大致月份即可；是否有课程、考试或毕业节点需要避开］ |
| 每周大致可投入时间 | ［现实可持续的小时数或时间段；不确定时写明］ |
| 所在时区与方便交流的时段 | ［例如 UTC+8，工作日傍晚；按本人情况填写］ |
| 交流语言 | ［中文／英文／均可；可补充口头或书面交流偏好］ |
| 希望获得的指导或资源 | ［阅读反馈、研究方法、同伴协作、数据、设备等；写出最需要的 1—2 项］ |
| 已知的原校安排或约束 | ［课程、导师、实习或外出要求；尚无导师可写“暂无”，制度不清楚可写“待确认”］ |

首次交流不要求已有两位导师。可以先讨论兴趣与可行的小任务，需要办理校际手续时，再共同核对相关要求。

## 四、竞赛想法（如适用）

- 想参加的竞赛或希望解决的问题：［赛事名称和当届规则链接；尚未选定可描述方向］。
- 当前想法、已有成员与本人可能承担的工作：［简单说明；个人来询问也可以］。
- 已知时间与组队条件：［报名或提交日期、跨校组队及代表学校要求；未知项写“待核对”］。

## 五、可复制的首次联系短文

通过[导师公开主页](https://h-jp.github.io/)所列的公开联系渠道发送。邮件主题可用：**科研／竞赛合作交流｜［学习阶段］｜［兴趣关键词］**。

> 您好！我是［学校、专业、学习阶段、称呼］，对［具体问题或方向］感兴趣，希望通过［科研／竞赛］合作学习［具体能力］。我曾尝试［课程项目、阅读、小练习或研究；简述本人贡献］，相关材料是［可分享链接；没有可说明］。我计划在［起止时间］以［远程／其他方式］参与，每周大致可投入［时间］，所在时区为［时区］，可用［中文／英文］交流。希望请您看看是否有适合讨论的小任务或合作机会，尤其想获得［具体指导］。附上简短意向说明，期待交流。谢谢！

发送前检查：

- [ ] 兴趣和时间安排已经写清。
- [ ] 链接可访问，材料有权分享。
- [ ] 本人贡献和希望的支持已经说明。

简短邮件正文也可以作为意向说明，不必重复制作附件。

## 六、交流后的下一步

如双方愿意继续，可用[科研训练任务卡](research-task.md)约定一个符合当前基础的小任务，通过[学习与成长复盘](learning-review.md)记录尝试、反馈和下一步。涉及正式接收、派出或联合培养时，再使用[跨校培养与指导约定](joint-training-plan.md)衔接必要安排。

收到回复或约定共同任务后，可按讨论结果推进；正式接收、注册或学分等事项仍以相应确认结果为准。将填写后的意向发送给拟联系的指导者即可，无需发布到官网。
