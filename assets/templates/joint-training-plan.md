# 跨校培养与指导约定：工作底稿

用途：用于接收外校学生、派出本校学生或远程共同指导前，协商培养目标、指导职责、资源和衔接安排。适用于本科科研训练、竞赛、毕业设计、硕士及博士培养，包括国际学生。

本模板是工作底稿，不替代校际协议、学校审批、学生注册、正式考核或学位认定。共同指导不自动产生联合学位或双学位资格。未确认事项保持“待确认”，写明联系人和处理日期，不预填“已批准”。

填写后放在双方授权的受控空间。官网只提供空白模板；公开介绍不附个人联系方式、签名、证件、未公开研究数据或完整协议。

使用顺序：[阅读联培指南](https://csma-graduation-projects.github.io/joint-training.html) → 共同填写本表 → 用[阶段与认定对照表](joint-training-recognition.md)核对正式要求 → 办理必要手续 → 按确认范围开展工作。

## 一、合作范围与适用依据

| 项目 | 填写内容 |
| --- | --- |
| 记录编号、版本和日期 | ［填写；修订时保留前一版本］ |
| 学生与培养类别 | ［姓名、年级；本科科研／竞赛／毕设、学术硕士／专业硕士、博士；当前阶段］ |
| 合作方向 | ［接收外校学生／派出本校学生／远程共同指导；以哪一单位为本表的记录方］ |
| 合作类型与范围 | ［科研合作、阶段访学、共同指导论文、正式联合培养项目等；是否涉及学分、实践或学位认定］ |
| 学籍所在单位 | ［学校、学院、项目；保持注册与培养联系的责任部门］ |
| 接收或合作单位 | ［学校、学院、研究团队；实际学习研究地点］ |
| 学位授予单位 | ［按适用项目填写；与学籍单位不同时分别列明；不涉及学位时注明］ |
| 合作期限与方式 | ［起止日期；驻校／远程／混合；返校和正式节点安排］ |
| 项目、协议与制度依据 | ［双方适用文件的名称、版本、条款、来源、核验日期；正式协议编号或办理状态］ |
| 当前待确认事项 | ［事项、影响、联系人、回复日期及未解决前可开展的范围］ |

不确定属于何种项目时，先请双方有权部门确认类型及手续，记录答复。不得仅因有两位导师就将合作填写为联合学位项目。

## 二、指导职责与沟通联系人

同一人可以承担多个角色，但每项职责仍需明确；姓名和联系方式仅保存在受控记录中。

| 角色 | 负责的具体事项 | 不在其权限内、需转交的事项 | 联系方式与替代联系人 |
| --- | --- | --- | --- |
| 学生 | ［制订计划、执行任务、保存证据、报告困难、主动对齐正式节点］ | ［需要导师或学校决定的事项］ | ［填写］ |
| 学籍所在学校导师 | ［整体培养、论文主线、本校节点衔接及约定的学术指导］ | ［需本校或其他单位正式审批的事项］ | ［填写］ |
| 接收或合作学校导师 | ［约定研究任务、方法反馈、资源及日常指导］ | ［不能代为确认的学籍、学分或学位事项］ | ［填写］ |
| 主要日常对接人 | ［谁接收进展、协调日程、处理日常问题］ | ［超出日常协调范围时如何转交］ | ［填写］ |
| 双方学院或相关部门 | ［分别填写接收、派出、实践、课程或其他手续的承办职责］ | ［其他有权单位及办理入口］ | ［填写］ |
| 学位授予单位相关部门 | ［如适用，填写正式学位审核与程序的联系职责］ | ［按正式权限填写］ | ［填写］ |

## 三、个人学习研究目标与任务验收

- 合作要解决的具体问题：［说明为何需要此次合作，以及可获得的指导、方法或资源］。
- 起点能力与证据：［当前能独立解释、实现、分析或验证什么；已有记录位置］。
- 合作结束时的能力目标：［用“能够独立……”表述，并说明检查方法］。
- 与本校培养或论文主线的关系：［合作任务如何支撑当前阶段；不纳入正式认定的任务也应说明］。

| 任务与时间 | 预期形成的能力 | 个人负责部分与协作边界 | 可提交材料与证据 | 检查人、方法及达到条件 |
| --- | --- | --- | --- | --- |
| ［最小起步任务］ | ［可观察的解释或操作能力］ | ［本人工作及依赖］ | ［产物、版本和原始记录］ | ［约定何时、由谁、如何检查］ |
| ［主要研究或实践任务］ | ［填写］ | ［填写］ | ［填写］ | ［填写］ |
| ［总结、返校或下一阶段任务］ | ［填写］ | ［填写］ | ［填写］ | ［填写］ |

按本人类别补充以下内容，不适用时说明理由。具体要求从本人适用文件核对，不采用统一时长、论文数量或成绩门槛。

| 培养类别 | 本次需要明确的内容 | 适用依据与确认安排 |
| --- | --- | --- |
| 本科科研训练、竞赛 | ［先修能力、任务难度、个人贡献；竞赛当届跨校组队、代表学校、作品和署名规则；项目或学分认定是否适用］ | ［填写］ |
| 本科毕业设计 | ［校外指导手续、校内指导人、任务书、开题中期、论文及答辩；项目验收与毕设评价分别由谁完成］ | ［填写］ |
| 学术硕士 | ［选题、研究方法、开题中期、成果要求、论文评阅答辩如何衔接；合作成果与论文的关系］ | ［填写］ |
| 专业硕士 | ［专业实践的资格、内容、过程、考核和正式认定；合作研究能否计入实践及确认部门］ | ［填写］ |
| 博士 | ［资格考核是否适用及与开题的关系、年度进展、研究主线、原创贡献和个人独立工作；指导委员会是否适用］ | ［填写］ |
| 国际学生及其他适用情况 | ［工作与材料语言、指导和学习支持；注册、居留、资助及跨境访问等事项的适用性和承办部门］ | ［填写；不自行推定手续适用或已经完成］ |

| 事项 | 提供方、承担方与范围 | 可使用日期及前置条件 | 尚缺事项与处理人 |

## 五、指导、反馈与意见协调

- 共用进展记录位置：［链接一份双方有权限查看的记录；复用[周报](weekly.md)，避免重复填报相同内容］。
- 常规反馈安排：［频率、语言、形式、主要指导人；按任务需要协商，不设置统一周期］。
- 双方共同检查安排：［日期或触发条件、需要提前提交的材料、双方各检查什么］。
- 会议与决定记录：［复用[会议记录](meeting.md)，区分建议、决定与待审批事项；注明谁确认哪一部分］。
- 意见或时间冲突处理：［学生记录差异和影响 → 双方导师协调研究安排 → 涉及制度事项交有权部门确认；负责人、期限、等待期间可独立推进的工作］。
- 反馈落实方式：［修改位置、证据、复查人及未解决问题的下一步］。

## 七、变更、延期、退出与返校

1. 触发条件：［任务不可行、资源中断、期限变化、指导人变化或其他实际原因］。
2. 处理路径：［先记录事实、影响和备选方案，使用[变更申请](change-request.md)保存原计划；明确谁协调、谁批准以及正式生效条件］。
3. 培养连续性：［未完成任务、本校节点、注册或资助可能受到的影响，以及替代指导安排］。
4. 结束或退出交接：［成果和资料清单、授权范围、设备归还、账号权限调整、费用结算及返校联系］。
5. 争议未解决时：［提交给谁、计划回复日期、可继续的授权工作；不自行将未解决事项写成双方同意］。

## 八、分项确认与启动检查

各行独立填写；研究计划得到导师认可不代表学校已批准派出或接收，也不代表学分、实践或学位已认定。

| 确认事项 | 实际状态 | 确认主体、日期及证据 | 下一步、责任人和期限 |
| --- | --- | --- | --- |
| 学生理解任务、边界与求助渠道 | ［待确认／已确认］ | ［填写］ | ［填写］ |
| 双方导师确认研究目标与分工 | ［分别填写，避免一方确认替代另一方］ | ［填写］ | ［填写］ |
| 所需学校审批或正式协议 | ［待核对／待申请／办理中／已批准／未批准／不适用并说明］ | ［有权主体及正式依据］ | ［填写］ |
| 接收条件及资源权限 | ［逐项填写实际状态］ | ［填写］ | ［填写］ |
| 后续正式考核与认定安排 | ［已核对／尚缺确认；结果另在阶段表填写］ | ［链接阶段与认定对照表］ | ［填写］ |
