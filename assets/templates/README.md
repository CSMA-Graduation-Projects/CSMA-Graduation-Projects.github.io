# 培养流程模板使用说明

这里提供 25 份可以下载、复制和填写的 Markdown 模板，覆盖本科科研训练、毕业设计、竞赛，以及硕士与博士研究、专业实践、学位论文和资料归档。模板用于组织工作与证据；学校、学院当年正式文件及表单优先。博士资格考核、研究主线与多项贡献整合在适用模板中单列填写项。

## 如何开始

1. 按当前阶段选择模板，保留原文件作为空白底稿，复制一份到自己的项目中填写。
2. 建议采用 `YYYY-MM-DD-项目代号-材料名称-v01.md` 命名。使用项目内相对路径关联代码、报告、运行记录与正式回执。
3. 将 `［填写］` 替换为实际内容。未知项写“待核实、责任人、核实日期”；不适用项说明理由；未执行的工作写“未执行”。
4. 完成自检后交给实际负责人员复核，记录意见、整改和确认日期。未审核不得预填“通过”。涉及学校审批的事项仍须走正式流程。

## 填写时保留的边界

- 正式要求、指导建议和个人计划分别记录，不自行规定统一论文数量、查重比例、实践时间或考勤时长。
- 真实运行、保存记录回放、作者报告、人工示例和待验证假设分别标注；“文件存在”或“脚本检查通过”不能替代实际研究验证。
- “查非”在本指引中指非学术性问题检查，具体名称及项目依学院规定；与查重、AI 使用声明分别处理。
- 投稿、接收、发表，报名、提交、获奖，以及申请、授权均为不同状态，按实际凭证填写。
- 模板中不写账号密钥、非必要个人信息或私有绝对路径。受限数据只记录获准使用的说明、版本标识与受控位置。
- 匿名送审版、答辩版和最终归档版分开管理。归档应包含真实生成的文件清单、校验值、恢复入口和未完成项说明。
